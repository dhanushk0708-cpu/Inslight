# INSLIGHT — Reusable UI Components

1. **`BrandLogo` (`frontend/src/components/ui/BrandLogo.tsx`):** Geometric SVG prism-and-chart emblem paired with gradient `INSLIGHT` wordmark, used consistently in the Sidebar, `/login`, and `/register`.
2. **`KPIGrid` (`frontend/src/features/analytics/KPIGrid.tsx`):** Executive KPI cards with `lucide-react` icons (`IndianRupee`, `Percent`, `Package`, `ShoppingCart`, `TrendingUp`, `BarChart3`), animated count-up numbers, top gradient accent stripe, and trend badges.
3. **`MarkdownRenderer` (`frontend/src/components/common/MarkdownRenderer.tsx`):** Zero-dependency React Markdown renderer for headings, dividers, bold/italic/code, and nested bullet/numbered lists.
4. **`ChatMessages` (`frontend/src/features/chat/ChatMessages.tsx`):** Distinct User vs. AI message bubbles with `Sparkles` avatar, `.thinking` pulse, and 3-dot typing indicator.
5. **`SkeletonCard` & `SkeletonGrid` (`frontend/src/components/ui/Skeleton.tsx`):** Shimmering placeholders displayed during async analytics/dashboard loading.
6. **`EmptyState` (`frontend/src/components/ui/EmptyState.tsx`):** Unified empty-state card with icon, title, description, and optional action button.
7. **Feature Workspaces:** `RootCausePanel`, `ForecastingPanel`, `AlertsPanel`, `DataQualityPanel`, `ComparisonPanel`, `DashboardStudio`, `RelationshipsPanel`, `ReportsView`, `PresentationStudio`, `NotificationsPanel`, `AdminPanel`, `WhatIfPanel`, `AnomaliesPanel`.
