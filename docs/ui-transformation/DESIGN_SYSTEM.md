# INSLIGHT — Design System

## Color Tokens (`frontend/src/app/globals.css`)
- **Primary Canvas:** `--bg-primary: #050811` (Deep midnight)
- **Elevated Surfaces:** `--bg-card: #0f1524`, `--bg-card-hover: #141c30`, `--bg-elevated: #172036`
- **Glass Topbar:** `--bg-glass: rgba(10, 15, 28, 0.82)` with `backdrop-filter: blur(16px)`
- **Brand Accents:** `--accent: #6366f1` (Indigo), `--accent-light: #818cf8`, `--purple: #8b5cf6`, `--blue: #38bdf8`
- **Semantic Status:** `--green: #10b981` (Opportunities / Positive), `--red: #ef4444` (Critical Risks / Errors), `--amber: #f59e0b` (Warnings / Hypotheses)
- **Typography:** `Inter`, `-apple-system`, `BlinkMacSystemFont`, `sans-serif`; crisp scale from `9.5px` uppercase badges to `24px` KPI values (`font-weight: 800`, `-0.6px` tracking).
- **Borders & Radii:** `--border: rgba(255, 255, 255, 0.07)`, `--radius: 14px`, `--radius-sm: 10px`, `--radius-full: 9999px`.
